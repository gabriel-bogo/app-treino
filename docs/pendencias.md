# Pendências (pedidos guardados para fazer depois)

Lista de ajustes pedidos que ainda não foram feitos. Só são executados quando pedido.

1. **Data de nascimento digitável:** campo de texto com máscara DD/MM/AAAA, em vez do seletor de data.
2. **Trocar o grupo muscular de cada treino:** na proposta do plano (e na aba Plano), além de trocar exercícios, poder escolher quais músculos cada treino trabalha. Ex. de uso: Treino A = Peito + Tríceps e Treino B = Ombros + Costas + Bíceps (o ombro sai do A e vai para o B, no lugar do peito). O app remonta os exercícios a partir dessa escolha.
